# Анализ температурных данных

Streamlit-приложение для исследования исторических температур и сравнения текущей
погоды с сезонной нормой. Данные — 15 городов, ежедневные наблюдения за 2010–2019 годы.

## Возможности

- **Описательная статистика** по выбранному городу в разрезе сезонов:
  среднее, стандартное отклонение, медиана, минимум и максимум.
- **Временной ряд** с 30-дневным скользящим средним, полосой сезонной нормы ±2σ
  и выделением аномальных дней точками.
- **Сезонный профиль** — столбчатая диаграмма средних с усами ±2σ.
- **Долгосрочный тренд** — линейная регрессия по десезонализованному ряду
  с наклоном в °C за десятилетие и p-value.
- **Сравнение последнего года** с десятилетней нормой по каждому сезону.
- **Текущая погода** через OpenWeatherMap API с проверкой на аномальность
  относительно исторической нормы текущего сезона.

Все графики интерактивные (plotly): масштабирование, подсказки при наведении,
отключение серий по клику в легенде.

## Структура

| Файл | Назначение |
